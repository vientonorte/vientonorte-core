# Canva.com via Safari

1. Use Safari, already logged in to Google. Do not use Chrome DevTools MCP (that profile has no Google login).
2. Do not ask el usuario to re-type a password. Use the saved Safari session.
3. Open `https://canva.com` in Safari (AppleScript or ask el usuario to focus the logged-in window).
4. Do not use the Canva plugin for this job.
5. After the asset is in Canva, stop. Do not export unless asked.

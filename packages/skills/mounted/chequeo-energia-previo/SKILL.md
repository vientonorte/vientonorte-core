name: chequeo-energia-previo
description: Use before a focus block, a meeting, or a long task the user is about to start.
---
Optional: the user can skip it anytime.

1. Ask three quick numbers: energy 1–5, body (ate / moved / slept), focus 1–5.
2. If 2 or less: suggest a micro-break (water, short walk, 5 min of music) or a light task.
3. If 4 or more: hardest task first.
4. Never interpret it clinically.
5. If logged, one line only in the user's own private notes (e.g. their Obsidian vault). Never in shared bot memory, shared Drive folders or the temporary box.
